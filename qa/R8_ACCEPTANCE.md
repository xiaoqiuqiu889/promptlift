# Prompt Lift 当前版本验收报告

## 验收范围

本轮围绕 8 个目标签收：16 组专属系统提示词、提示词页面单滚动与去重、界面层级优化、小狗鼻梁毛色修正、可爱待机表现、服务内容并入“我的”、底部页签精简，以及桌面精灵右上角等比缩放。

## 逐项结果

| 验收项 | 结果 | 核验证据 |
| --- | --- | --- |
| 4 场景 × 4 档位专属提示词 | 通过 | 16 个组合均返回不同且实质差异化的系统提示词；场景和档位变化会立即刷新当前提示词。 |

## 安全与回归边界

- API Key 仍由当前 Windows 用户的 Electron `safeStorage` 加密保存，不进入源码、日志、文档或验收证据。
- 原文、目标窗口、进程与 CAS 操作令牌校验保持不变；提示词、交互或模型失败时不会盲目覆盖当前输入。
- 16 组默认系统提示词仍受不可关闭的安全协议、事实锚点、档位边界和输出协议保护；本机自定义规则只能作为低优先级补充。
- 默认双击 Alt 的零选择快速路径保持不变；精灵缩放手势不会调用 capture、enhance 或 apply。
- 待机动画只改变视觉变换，不改变布局、点击命中或透明切图边缘。
