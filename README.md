# Prompt Lift 🐾｜给文字装上小翅膀

> 一个住在 Windows 输入框旁边的小精灵：双击一下 `Alt`，让想法更清楚、语气更合适、提示词更好用。

有些话不是不会说，只是还差一点点整理。Prompt Lift 就负责这“一点点”——它读取当前输入框里的文字，交给模型做一次有边界的优化，再把选择权交还给你：预览、复制、应用、重试，或者恢复原文，随你安排。

它不是会抢话的聊天机器人，也不会偷偷替你做决定。它更像一位安静但靠谱的表达搭子：需要时出现，用完就退到一边。

## 它最擅长的四种表达

| 场景 | 适合拿来做什么 | 它会重点帮你整理什么 |
| --- | --- | --- |
| **AI 提示词** | 写给 AI 的任务说明 | 目标、上下文、约束、验收标准和输出格式；只改提示词，不替你执行原任务 |
| **向上沟通** | 给老板、负责人或跨团队伙伴发消息 | 先讲结论，再整理依据、风险、需要的支持和下一步 |
| **用户沟通** | 客服、运营、销售和日常对外表达 | 更安全、更礼貌、更清晰，避免过度承诺和模糊措辞 |
| **PPT 文案** | 优化一段标题或正文 | 把描述性标题变成结论型标题，让一页内容更容易被看懂 |

## 四档风格，不是四个换皮按钮

- **原意守护**：轻轻整理，不乱动你的原话，适合“帮我顺一下，但别改味儿”。
- **清晰直达**：删掉绕口和重复，让重点先到达，适合高频快速发送。
- **专业展开**：把已有逻辑、条件、风险和行动项排整齐，适合正式沟通和复杂提示词。
- **创意策划**：在事实不变、范围受控的前提下，增加更有记忆点的结构、标题或表达角度。

四档会根据不同场景使用不同的系统提示词，不是同一段话换四个名字。非创意档位不扩散应用场景；所有档位都保留原文锚点和语气强度，创意档位也有长度上限。

## 三秒上手

1. 打开任意可以输入文字的 Windows 应用，把光标放进输入框。
2. 双击左 `Alt`，或者单击桌面上的小精灵。
3. 第一次使用时，进入“我的 → 模型与 Key 配置”，填好接口地址、模型名和 API Key，点击“检查并保存”。
4. 在“处理”页选择表达场景，再选择优化档位，然后交给 Prompt Lift 整理。
5. 结果出现后，可以直接应用；也可以打开审阅，复制、重新生成、恢复原文或放弃。

想换快捷键？去“我的 → 全局快捷键”录制新的组合键即可。双击 `Alt` 仍然是默认的零选择快捷入口，懒得设置也完全没关系。

## 小精灵图鉴 🐶⚔️

- **原始可卡布犬**：毛茸茸的老朋友，负责可爱待机。
- **绿色骑士小狗**：穿上绿色小盔甲，透明无边框，脸部毛色按真实参考校准。
- **CSS 绿色骑士**：经典绿色骑士，像素感和几何感都保留。

桌面状态下，按住小狗本体可以移动它；把鼠标放到右上角的三个轻量圆点，可以等比例缩放。拖拽使用 Windows 原生光标坐标，缩放期间保持稳定绘制面，尽量做到“指哪儿到哪儿”，不乱飞、不闪烁、不突然裁掉耳朵。

## 安全小管家，绝不自作主张

- **预览后再决定**：可以开启“审阅后应用”，先看差异，再决定是否回填。
- **安全替换**：应用前核对目标窗口、进程、原始文本和操作令牌；输入框被别人改过时，不会盲目覆盖。
- **原文可恢复**：取消、恢复和失败路径都不会悄悄吞掉原文。
- **不伪造完成状态**：待审计、待检查、待开发仍然保持未完成；仓库链接、文件路径和截图只是待检查对象，不会被包装成“已经看过”。
- **不追加请示句**：任务已经明确时，模型不会在结尾突然问“要不要我继续”“是否需要我开始”。遇到这类 badcase，结果会被拦截并自动纠正一次。
- **凭据不乱跑**：API Key 通过 Electron 的 Windows `safeStorage` 加密保存，只对当前 Windows 用户可用，不写进源码、日志或打包资源。

## 系统提示词？可以看，也可以改

在“我的 → 系统提示词”里，可以切换 4 个表达场景和 4 个优化档位，查看当前实际使用的规则。每个“场景 × 档位”都有自己的提示词合同；你还可以添加一段有长度上限的自定义补充规则。

自定义规则只能做低优先级补充，不能覆盖安全协议、原文事实、场景目标或档位约束。简单说：可以告诉它“更像我一点”，不能要求它“把事实改了”。

## Windows 运行方式

### 推荐：下载完整 ZIP

1. 下载仓库里唯一的最新版 [Prompt-Lift-latest-win32-x64.zip](deliverables/Prompt-Lift-latest-win32-x64.zip)，并可用同目录的 [SHA256SUMS.txt](deliverables/SHA256SUMS.txt) 校验完整性。
2. 将 ZIP 解压到一个有写入权限的目录。
3. 先退出系统托盘中已经运行的旧版 Prompt Lift。
4. 双击解压目录中的 `Prompt Lift-win32-x64/Prompt Lift.exe`。

这是 Windows x64 便携包，已经包含运行时，不需要额外安装 Node.js、npm 或命令行工具。**不要只把 EXE 单独拎出来运行**，请保留它旁边的整个 `Prompt Lift-win32-x64` 文件夹——小精灵的行李箱也要一起带上。

仓库只保留一个最新版 ZIP，不提交解压后的 Electron 运行目录、历史发布包或自动化截图，让下载入口保持清爽。

## PPT 文案场景的边界

PPT 文案场景适合把当前输入的一段标题或正文整理成“一个结论 + 清晰层级”的文案。它不会假装读取整个演示文稿，也不会凭空理解其他文本框、图表、备注或版式；如果需要整套 PPT 改稿，请先把需要处理的文字汇总到当前输入框。

## 开发与技术栈

- Electron + Node.js
- 原生 HTML / CSS / JavaScript 渲染界面
- Windows 原生输入捕获与原子化替换桥接
- Electron `safeStorage` 保护模型凭据
- 版本化 Recipe 与模型侧系统提示词协议
- Git LFS 管理便携版 EXE 和 ZIP 发布文件

核心原则只有一句：**先保护原文，再谈增强。** 输入内容按不可信材料传给模型，系统规则优先于场景、档位和用户文本；结果必须通过协议、语言、长度和不可变锚点校验后，才允许进入替换流程。
